# Blunesie

Boutique front-end prête à ouvrir pour la marque de vêtements Blunesie.

## Utilisation

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages dans **Settings → Pages** en choisissant la branche `main` et le dossier `/ (root)`.

Le site est une maquette e-commerce responsive avec navigation, catalogue et compteur de panier. Les images de campagne et les vrais produits peuvent ensuite être ajoutés.
